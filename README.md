# quasard-lite

Автономный бэкенд для Яндекс Станции: когда компьютер-сервер выключен,
колонка продолжает работать сама. `quasard-lite` отвечает колонке вместо
облака Алисы по её же протоколу (uniproxy/glagol), поэтому станция
активируется, говорит и играет как обычно.

## Что умеет

- **Музыка** — поиск по исполнителю/треку из открытых баз (SkySound7,
  muzofond, mp3xa, muzmo, drivemusic, Internet Archive), «включи музыку /
  моя волна» — топ Deezer, найденный в тех же базах.
- **Радио и аудиокниги** — icecast-радио через локальный прокси (без ICY-
  метаданных, с автореконнектом) и книги с полок archive.org
  (`librivoxaudio`, `audio_bookspoetry`, `audioboo_ru` — включая русские).
- **Таймеры и будильники** — родными директивами: колонка отсчитывает и
  звенит сама, даже если lite упал.
- **Голос без облака** — микрофон профиля «Олег» (UDP PCM) → бесплатное
  распознавание → команда колонке; активация только после слова-вызова.
- **Погода и курсы** — Open-Meteo / wttr.in, ЦБ РФ / open.er-api.
- **Ответы на вопросы** — цепочка LLM-провайдеров (Pollinations работает
  без ключа; Orca/SambaNova/Mistral/z.ai — по ключу).
- **Управление** — громкость, «стоп/пауза», подсветка кольца, Bluetooth-
  настройка Wi-Fi, HTTP-API пульта (`/_mgmt/*`, токен в заголовке `X-Token`).
- **Опциональный релей** к настоящему облаку Яндекса для ASR/TTS
  (`[net] relay = true`) или полностью автономная работа (`relay = false`).

## Структура

```
column_lite/   ядро lite: HTTP/WS-сервер, relay, музыка/книги/радио,
               голос, таймеры, погода, LLM-клиент, скрипты запуска
mobile/        Android-пульт (вкладки: история, Wi-Fi, Bluetooth; ui.html)
tests/         тесты: tests/lite (ядро), tests/llm (маршрутизация LLM)
tools/         deploy_lite.py, send_lite.py, voice_inject.py, gen_certs.py и др.
```

## Требования

- Яндекс Станция с root/adb-доступом и локальным Python 3.12
  (`/data/opt/python`), библиотеки `httpx`, `websockets`, `protobuf`.
- Запись устройства, снятая с колонки: `data/devices/<серийник>.json`
  с `id`, glagol-сертификатом и ключом. Без неё lite не отдаст колонке
  `sync_info.glagol` и голосовой канал не поднимется.
- Для голоса без ПК — профиль «Олег» на колонке (микрофонный PCM на UDP
  порта компьютера; автономный режим перенаправляет его на саму колонку).

## Быстрый старт

```bash
# 1) Сертификаты для HTTPS/WSS (колонка уже будет им доверять после установки CA)
python tools/gen_certs.py --ip <адрес колонки>

# 2) Развёртывание на колонку через adb
python tools/deploy_lite.py --ip <адрес колонки> --pc-ip <адрес компьютера>

# 3) Перезапуск ядра
adb shell sh /data/opt/column_lite/S99zlite restart
```

`--pc-ip` нужен голосу без ПК: профиль «Олег» шлёт микрофон на адрес
компьютера, и lite ставит DNAT этого потока на себя. Без `--pc-ip`
работают музыка, радио, книги, таймеры и текстовые команды, но не голос.

## Конфигурация

Файл `lite.toml` рядом с кодом на колонке (в git не попадает):

```toml
[device]
device_id = ""        # пусто — берётся из device.json
city = "Москва"       # для фраз о погоде
latitude = 55.75
longitude = 37.61

[server]
http_port = 80

[voice]
port = 5600

[llm]
# ключи провайдеров: mistral_key, zai_key, sambanova_key, orca_key …

[net]
relay = true          # false — полностью без облака Яндекса
```

Без `device_id`, `city` и координат lite работает, но погода спросит
город, а голосовой канал ограничится текстовыми командами.

## Тесты и линтер

```bash
python -m pytest tests/lite -q
ruff check column_lite --select F,B,E7,E9
```

## Приватность

В репозитории нет серийников, IP-адресов и координат: всё задаётся при
развёртывании (`device.json`, `lite.toml`, флаги `deploy_lite.py`).
`config.toml`, `data/`, `certs/`, `*.key`, логи и записи звука исключены
через `.gitignore`.
